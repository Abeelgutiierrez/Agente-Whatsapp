# Clínica Armonía — Demo v0.1.0

Primera versión demostrable del sistema de reservas Clínica Armonía.

Esta versión está diseñada exclusivamente para demostraciones comerciales con datos ficticios. Incluye reserva online, agenda del negocio, gestión de citas y clientes, indicadores, recomendaciones, configuración y exportación.

No está preparada para producción y no incluye integración real con WhatsApp, autenticación, pagos, historia clínica ni cumplimiento regulatorio certificado.

Versión preparada: `v0.1.0-demo`. La publicación debe marcarse como **pre-release**.
